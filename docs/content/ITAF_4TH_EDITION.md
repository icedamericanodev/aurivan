# ITAF IS Audit and Assurance Standards — verified numbering

Edition checked: ITAF 4th edition (ISACA, October 2020). ISACA published a 5th edition on 26 February 2026. Search results say the 5th edition keeps the same standard structure: 1201 is still Risk Assessment in Planning and 1202 is still Audit Scheduling. The 1000, 1200 and 1400 titles below are therefore current. I could not open the 5th edition text itself. See the caveats section.

Method: the egress proxy blocked direct fetches of isaca.org, famu.edu (which hosts the 4th edition PDF), pdfcoffee.com and the other secondary sites, so I could not read any primary text. The mapping below comes from several web-search result sets that index the ITAF 4th edition PDF and ISACA pages. Each number/title was returned consistently across them.

## Performance standards (1200 series)

| No. | Title (4th ed.) | 3rd ed. (2014) title at same number |
|---|---|---|
| 1201 | Risk Assessment in Planning | Engagement Planning |
| 1202 | Audit Scheduling | Risk Assessment in Planning |
| 1203 | Engagement Planning | Performance and Supervision |
| 1204 | Performance and Supervision | Materiality |
| 1205 | Evidence | Evidence |
| 1206 | Using the Work of Other Experts | Using the Work of Other Experts |
| 1207 | Irregularities and Illegal Acts | Irregularity and Illegal Acts |

- Materiality is no longer a stand-alone standard in the 4th edition.
- **There is no Standard 1208** in either edition. "1208 (Audit Documentation)" does not exist.

## Reviewer claims

| Claim | Verdict |
|---|---|
| 1201 is now "Risk Assessment in Planning" | **Confirmed** |
| 1203 is "Performance and Supervision" | **Incorrect.** 1203 is Engagement Planning; Performance and Supervision is **1204** |
| 1003 is "Auditor Objectivity" | **Confirmed** |
| "Standard 1208 (Audit Documentation)" does not exist | **Confirmed** |

## Related ISACA items verified (used in fixes)

- ITAF Companion Performance Guidelines 2208: Information Technology Audit Sampling. Carried forward and updated in the 5th edition.
- Verified ISACA audit programs: Information Security Management Audit/Assurance Program (WAPISM); Outsourced IT Environments Audit/Assurance Program (WAPOE); Systems Development and Project Management Audit Program (WAPDP); Change Management Audit Program (WAPCM1); Identity and Access Management Audit Program (WAIAM, 2022); IT Business Continuity/Disaster Recovery Audit Program (WAITBC, 2021); Cloud Computing Management Audit Program; Ransomware Readiness Audit Program (2022); Cybersecurity Audit Program (NIST CSF 2.0); Data Privacy Audit/Assurance Program (2017); Mobile Computing Security Audit Program.
- "Auditing Artificial Intelligence" is a 2018 ISACA **white paper**, not an audit program. ISACA's AI audit tool is the Artificial Intelligence Audit Toolkit.
- No ISACA "Vendor Management Audit/Assurance Program", "Business Continuity Management Audit/Assurance Program" or "Network Perimeter Security Audit/Assurance Program" could be verified.

## Caveats / UNVERIFIED

- I did not read the 5th edition (2026) standard texts directly. The claim that the numbering is unchanged rests only on search summaries.
- I could not establish the exact titles of ITAF 4th-edition guidelines other than 2208, so I did not cite them.
