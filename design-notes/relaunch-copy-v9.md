You signed up months ago to hear when this came back online.

We spent six months rebuilding the question bank from scratch. The old bank was derivative — questions that traced back to recycled exam prep material rather than the source standards. We didn't want to ship that.

**v9.0 has 1,004 original questions**, every one authored directly from public ISACA, NIST, and ISO standards with no exam-bank citations in the chain. 401 are analysis-tier and include a full scenario context — the kind the actual exam uses, not simplified drill questions.

We also built something we've wanted for a while: a **Principles Library**. Fifteen single-focus auditor-mindset principles — CONTAIN-FIRST, REVOCATION-FIRST, METHODOLOGY-RIGOR-FIRST, and twelve more — that sit underneath the question bank as a pedagogical layer. Each question is tagged to the principles it exercises. Each principle links back to the questions that test it.

Every question now ships with **three tips** after you answer: the trap (what the wrong options want you to do), the mindset (which principle applies and why), and the exam-day shortcut (the pattern to commit to memory).

**v9.0 — Rebuilt from source**

- **401 analysis-tier questions now include scenario context** — an 80–160 word incident brief rendered before the question stem, formatted to separate context → question → options as distinct reading phases.
