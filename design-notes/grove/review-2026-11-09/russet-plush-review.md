# Russet plush reference correction

Lumi was resolved unambiguously from the connected pet library as the user's active custom Dot pet. Its existing sprite sheet was inspected read-only. The actual reference has dimensional plush texture, warm stitched material, oversized glossy eyes, rounded toy proportions, and pose-specific blinking, waving and directional movement. Earlier generic SVG designs failed to match that reference.

The revised original fox kin, Russet, uses that rendering quality with its own apricot fox anatomy, cream facial mask, tail and sage leaf neckerchief. The Scout evolution adds a forehead tuft, fuller chest and layered leaves. The focused preview demonstrates a generated blink strip and a Cub-to-Scout reveal within the KaiSip companion-page styling. It is a style trial for one character, before revising the entire collection.

Open russet-plush-preview.html, or use the inline trial. Choose Try evolution, Back to Cub and Replay blink. Gentle motion and the device's Reduce Motion preference control playback.

## Scope and quality

Generated with the built-in image-generation tool using a cropped Lumi frame as a style reference. Lumi's actual pet record and selection were not edited. The reference sprite sheet and its temporary download URL are excluded from GitHub review artifacts.

The two-character evolution composition twice retained an unwanted background and was rejected for UI use. A separate transparent Scout asset replaced it. The Cub, Scout and idle assets have alpha channels. The idle strip contains six distinct generated poses. The preview uses the five compatible poses from the second through sixth cells for its blink cycle. There is slight pose/scale variation between generated cells, so this remains a motion-style trial requiring registration refinement before production. No full nine-state pet package or 16-direction set was created or validated for Russet.

Common sprite margins were cropped, assets were resized and encoded to WebP with quality 86, and the idle strip was inspected on Grove paper. Syntax checks passed for the focused preview. Full browser/mobile rendering and native performance are unverified.

The three shipped runtime assets (cub.webp, scout.webp and idle-trim.webp) have measured encoded sizes recorded below. They describe one two-form style trial, not the 12-kin collection or installed app impact. The old 9 KB figure applies only to the rejected procedural vector roster. Final plush collection size depends on asset resolution, number of forms and animation frames, compression and reuse. Match the visual direction before selecting a production asset budget.
