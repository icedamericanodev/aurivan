# Grove Kin in the existing KaiSip UI

This concept supersedes the broader Home/You redesign in the earlier audit. The owner chose to retain the existing KaiSip screens and Grove identity and focus on simplifying the plant experience.

Reviewed current checkout HEAD f4a99e3001aec39cc82fd09f9fafdf6ad27edec7 read-only. The plant page, PlantPage components and theme tokens have no differences from the previously reviewed 70e1ca7 baseline. The source uses a back-to-You header, illustration directly on paper and a soil line, then a left-aligned name block and supporting controls. The historical store plant screenshot supplied the visual reference. The source supplied the current layout.

## Three views

1. Companion. Pip occupies the existing plant illustration area. Its name and form sit below. One forest panel gives one next evolution milestone. A collection row and Rename replace the dense growth and customization presentation in this concept.
2. Collection. A new subpage reached from that row uses the same paper, ink and type language. Earned creatures have their own illustrations. A subtle check identifies the active companion. One upcoming discovery appears alongside the earned collection.
3. Evolution. The same companion screen reveals the grown form after a qualifying milestone. A short before/after sequence explains the change. Continue is the primary action.

## Proposed interaction

Pip is an original seed creature with leaf ears and root feet. Its Leaf form keeps the same identity with a fuller leaf collar. Mossback is a low woodland creature with a mossy shell and fern tail. Luma is a petal-winged creature. These are concept designs and working names.

Finishing a normal study activity contributes to progress. Selected milestones trigger a new discovery or evolution. The mock uses first-topic completion for Pip and a completed review for the next discovery. The exact earning rules require reconciliation with existing milestone events before implementation.

On a new discovery, show one short result row such as “You met Mossback”, opening its collection entry when tapped. Collected kin remain available during breaks. Repeated activity should not duplicate a milestone reward. Existing plant names, growth and unlocks need an explicit migration mapping before replacing their production representation.

The proposed evolution animation is a brief crossfade from Seed to Leaf, followed by the still final state. Reduced Motion shows the final state immediately. The supplied image depicts that final state and is static.

## Fidelity and limitations

Generated using the built-in image-generation tool with the existing plant screenshot as a reference and current source layout as constraints. This is a visual concept, not a rendered app or a working animation. It approximates Fraunces/Figtree and original botanical linework. It retains the screen’s hierarchy and Grove materials while proposing new creatures, simplified copy, one milestone panel and a collection subpage. Browser/device fidelity and accessibility are unverified.

All production and emulator work remains outside this concept task. Files are saved as additional review artifacts on the existing GitHub draft branch.
