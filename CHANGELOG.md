# Changelog

All notable user-facing changes to this app. The in-app **What's New** modal mirrors this file; both are written for CISA candidates rather than developers. Format follows [Keep a Changelog](https://keepachangelog.com/) loosely, with the project's own **New / Improved / Fixed** categories.

For internal/technical history, see git log and PR descriptions.

## [v9.3] — Domain 3 audit pass: clearer questions, sharper teaching

### Improved
- Tightened question stems across Domain 3 to remove redundant qualifier words, so the exam-style precision word does the work it is supposed to do.
- Added closing audit-mindset sentences to several Domain 3 explanations so the principle being tested is named, not just inferred.
- Strengthened wrong-answer explanations on Domain 3 questions where the trap was being dismissed instead of taught.

### Fixed
- Domain 3 D3-124 explanation no longer cites OCC mergers-and-acquisitions guidance for a certification-and-accreditation question.
- Updated Domain 3 third-party-risk citations to reflect that OCC Bulletin 2013-29 was superseded in June 2023 by the Interagency Guidance on Third-Party Relationships.

## [v8.7] — Cleaner What's New

### Improved
- This What's New section now groups updates by **New / Improved / Fixed** for easier scanning. Older entries are simplified and free of jargon.
- Behind-the-scenes: the changelog is now data-driven, so adding future entries is a one-line change instead of a copy-paste of HTML.

## [v8.6] — Accurate exam blueprint weights

### Improved
- Domain weights now match the current ISACA blueprint everywhere — D1 18%, D2 18%, D3 12%, D4 26%, D5 26%.

## [v8.5] — Send feedback in one click

### New
- Send feedback right from the app — no need to leave for your mail client.

### Improved
- "Open mail app instead" remains as a one-click fallback for those who prefer their own email.

## [v8.4] — Cleaner header + clearer Domain Performance

### New
- Send Feedback button added to the header so suggestions and bug reports take seconds.

### Improved
- Header pill now shows just the app version; question count moved into onboarding.
- Domain Performance cards label each number ("Score" and "Seen") instead of cryptic dual fractions.

## [v8.3] — Tips for every question + mock exam fixes

### New
- Every question across all 5 domains now includes pattern-recognition tips — trap-naming, mindset/principle, and exam-day shortcut.

### Improved
- Subtopic categories tightened in D4 and D5 for sharper drill-down filtering.

### Fixed
- Mock exam answer buttons are responsive again.
- Mock exam timer stays continuous between questions.

## [v8.2] — Guided first-use onboarding

### New
- First-time users are walked through a 3-step setup: overview, profile, and exam date.
- A recommended first action appears right after onboarding so you know where to start.

## [v8.1] — Dark mode + visual refresh

### New
- Dark mode (defaults on) with a sun/moon toggle in the header — preference saves across sessions.

### Improved
- New color system across the app for a more focused study feel.

### Fixed
- Several text-readability issues on dark banners.

## [v8.0] — Daily plan + auditor mindset

### New
- Personalized 3-step daily study plan on the dashboard, driven by your domain scores and exam date.
- Auditor-vs-implementer coaching — when you pick the implementer answer, a callout explains the difference inline.
- Install the app to your home screen (PWA) and study offline.

### Improved
- Each topic now shows an estimated reading time.

## [v7.0] — Exam date + readiness score

### New
- Set your exam date and see a weighted readiness score across domains.
- Train My Weak Spots — one-tap 20-question drill from your weakest domains.
- Bookmark tagging and bookmark drill mode.

### Improved
- Pacing feedback during sessions and auto-save during mock exams.

## [v6.0] — UX overhaul

### New
- Rate your confidence before answering, for smarter spaced repetition.
- Drill into specific sub-topics within each domain.

### Improved
- High-impact domain badges (D4/D5) and a mock exam confirmation step before you begin.

## [v5.x] — Topics, profiles, export/import

### New
- Topic Summary tab with board-style review cards.
- Multiple profiles — separate progress per study cycle or per person.
- Export and import your progress as a JSON file.

### Fixed
- Several modal, timer, and race-condition issues.

## [v4.0] and earlier — Foundations

### New
- Local persistence, mock exams, weak spots, bookmarks, spaced repetition, all 5 domains, and configurable session timers.
