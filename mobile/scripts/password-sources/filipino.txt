# Filipino passwords and their building blocks (hand-written for KaiSip,
# 28 Nov 2026; many of KaiSip's learners are Filipino, and the public lists
# the app also uses are mostly American). One entry per line; spaces,
# capitals and punctuation are ignored (the compared form), so "mahal kita"
# also catches "MahalKita2026". Each entry counts as ONE common word in the
# whole-password rule, so a passphrase of three or more different words
# still passes ("kape muna bago mag aral").
#
# Lines starting with "~" are rude words, stored scrambled (letters ROT13,
# digits ROT5) so the file reads cleanly. Everything else is listed, by
# category, in docs/content/PASSWORD_LIST_FILIPINO.md for the owner to
# review (a test keeps the two the same).
# Built into the lazy word file by scripts/build-password-blocklist.mjs.
